# Simulation screenshots and screen recordings

Generated by `python bot_simulation/record_demo.py --seed 2025`. The robot in these recordings is driven by the same `chotu_core.CleaningMission` code that runs on the Raspberry Pi 4.

| File | What it shows |
|---|---|
| `01_mission_start_docked.png` … `12_ir_beacon_docking.png` | Flow-wise screenshots, one per mission phase: dock, undock, 360° mapping scan, adaptive suction boost, boustrophedon coverage, reactive obstacle avoidance, YOLO *avoid* cable keep-out, spot clean / frontier fill, progress at T+150 s, stuck recovery, A* return, IR-beacon docking |
| `13_mission_report.png` | Final mission report and AtomQuest rubric |
| `chotu_full_mission_recording.mp4` | **Full-length, real-time (1×) recording** of the whole dock-to-dock mission (~5 min, H.264 1280×720 at 20 fps) |
| `chotu_fleet_4_rooms_timelapse.mp4` | 4 robots in 4 different random rooms on the fleet dashboard (3× time-lapse) |
| `fleet_dashboard_4_robots.png`, `fleet_dashboard_final.png` | Fleet dashboard mid-mission and at the end |
| `benchmark_10_rooms_and_vision_ablation.png` | Coverage and time per room, plus the AI-vision ablation (camera on vs off) |
| `benchmark_40_rooms.json` | 40-room robustness benchmark (`run_simulation.py --benchmark 40 --seed 10`) |
| `mission_metrics.json` | Raw metrics: recorded run, fleet rooms, 10-room benchmark |

The images and videos are rendered from the simulator's frame buffer, not captured from the desktop, so they are reproducible on any machine.
